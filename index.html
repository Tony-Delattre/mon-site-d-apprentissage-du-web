Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Un ensemble de pages interconnectés par des liens hypertextes accessible depuis un navigateur.

Internet

Un réseau mondial qui relie les ordinateurs entre eux et qui heberge de nombreux services (web ; e-mail ; FTP ; newsgroups ...).

Cloud

Infrastructures et serveurs distants accessibles via Internet. Il permet de stocker des données, d'exécuter des applications et de louer de la puissance de calcul à la demande, sans avoir à gérer de matériel physique sur place.

W3C

(World Wide Web Consortium)
Organisme international qui développe et publie des standards et recommandations pour les technologies du Web, notamment HTML, CSS et les API Web.

Il veille à ce que le Web reste ouvert, accessible et compatible avec les différents navigateurs et appareils.

Partie 2 - Distinguez les langages du Web

Langages client

(Langage frontend) Un langage de programmation dont le code est téléchargé puis exécuté directement par le navigateur web sur l'appareil de l'utilisateur.

Son rôle est de gérer l'apparence visuelle, la mise en page, l'interactivité et l'expérience utilisateur immédiate, sans avoir besoin de solliciter le serveur à chaque clic.

Navigateurs

Un logiciel qui permet d'afficher et de naviguer sur le web, son rôle principal est de traduire le code envoyé par les serveurs (HTML, CSS, JavaScript) en une interface visuelle, interactive et compréhensible par l'être humain.

Langages serveur

(Langage backend) Un langage de programmation qui s'exécute sur le serveur distant et non sur l'appareil de l'utilisateur.

Son rôle est de traiter les requêtes envoyées par le navigateur, d'interagir avec la base de données, de vérifier la sécurité (authentification, mots de passe) et de générer une réponse avant de la renvoyer au client.

Frameworks

(Cadre de travail) Un ensemble structuré d’outils, de bibliothèques, de conventions et de composants qui fournit une base pour développer une application plus rapidement et de manière organisée.

Il impose ou propose une structure de développement sur laquelle les développeurs peuvent s’appuyer, évitant ainsi de devoir recréer certaines fonctionnalités et organisations de base à partir de zéro.

Bases de données

Un système informatique permettant de stocker, organiser et manipuler des données de façon structurée, sécurisée et facilement accessible par des applications ou des utilisateurs.

Site responsive

Un site web conçu pour s'adapter automatiquement à la taille de l'écran sur lequel il est affiché, qu'il s'agisse d'un smartphone, d'une tablette, d'un ordinateur portable ou d'un grand écran de bureau.

Application mobile

Un programme informatique conçu et optimisé pour s'exécuter sur un appareil mobile autonome (smartphone, tablette ou montre connectée).

Contrairement à un site web accessible depuis un navigateur, l'application mobile tire parti du système d'exploitation de l'appareil.

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Ordinateur ou système informatique qui fournit des services, des ressources ou des données à d’autres appareils ou logiciels appelés clients, à travers un réseau local ou Internet.

Adresse IP

Un numéro d'identification unique attribué à chaque appareil (ordinateur, smartphone, serveur, imprimante) connecté à un réseau informatique utilisant Internet.

C'est l'équivalent d'une adresse postale pour le monde numérique : elle permet aux données de savoir d'où elles partent et où elles doivent arriver.

Nom d’hôte et DNS

Le nom d'hôte :
Le nom attribué à un appareil sur un réseau, pour que l'on puisse le reconnaître facilement sans retenir l'adresse IP.

Le DNS :
(Système de noms de domaine) est l'annuaire d'Internet.
Le DNS associe des noms (noms d'hôtes, noms de domaine ...) à des adresses IP, pour que les humains n'aient pas à retenir des chiffres.

Protocoles

Les langages de communication utilisé par les machines pour se parler entre elles.
Exemples : TCP ; HTTPS ; FTP ; SMTP ...

Partie 4 - Identifiez les métiers du web

Développeurs

Conçoit, développe, teste, documente et maintient des sites web, des applications ou des logiciels en écrivant et en faisant évoluer leur code.

Product Managers et chefs de projets

Le Product Manager :
Définit la vision stratégique et les objectifs d’un produit, en veillant à répondre aux besoins des utilisateurs et du marché tout en respectant les objectifs de l’entreprise.

Chef de projets :
Planifie, coordonne et suit la réalisation d’un projet en gérant le budget, les délais, les ressources et les risques afin de garantir sa livraison conformément au cahier des charges.

Designers

L'UX Designer :
Conçoit l'organisation, le parcours et les interactions d'un produit afin de rendre son utilisation simple, intuitive et agréable.

L'UI Designer :
Conçoit l'interface visuelle d'un produit (couleurs, typographie, boutons, icônes, animations, mise en page) afin de la rendre claire, cohérente et esthétique.

Testeurs

Vérifie la qualité, la conformité et le bon fonctionnement d’un logiciel ou d’une application en détectant les erreurs et les anomalies avant sa mise en production et lors de ses évolutions.

Techniciens informatique

Gère et maintient le parc informatique d’une entreprise, assure le support technique aux utilisateurs et veille au bon fonctionnement des équipements et des accès au réseau.

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Habillage visuel du site Web. Il définit le style et la mise en forme du contenu, comme les couleurs, les polices, la disposition des éléments et l'adaptation aux écrans.

JavaScript

Front-End

Cerveau et dynamisme du site Web. Il définit le comportement et l'interactivité du contenu, comme les animations, la validation des formulaires, le réaffichage d'éléments sans recharger la page ou les actions au clic.

JavaScript

Back-End

Moteur invisible du site Web. Il gère la logique côté serveur, comme l'accès aux bases de données, la gestion des comptes utilisateurs, la sécurité et le traitement des commandes.

PHP

Back-End

Moteur du site Web côté serveur. Il génère du contenu dynamique, gère la logique métier, communique avec les bases de données et traite les formulaires avant d'envoyer la page au navigateur.

Java

Back-End

Moteur d'applications polyvalent et robuste. Il gère la logique côté serveur des systèmes à fort trafic, la gestion des données sécurisées et le fonctionnement d'applications complexes (notamment Android ou logiciels d'entreprise).

Python

Back-End

Moteur d'applications polyvalent et intelligent. Il gère la logique côté serveur des sites web, le traitement automatisé des données et le fonctionnement des algorithmes d'intelligence artificielle et d'analyse statistique.

Back-End

Moteur d'applications hautes performances du système Microsoft. Il gère la logique côté serveur des logiciels d'entreprise, les applications web sécurisées, les services cloud et le développement de jeux vidéo (notamment avec le moteur Unity).

SQL

Bases de données

Chef d'orchestre de la base de données. Il permet de communiquer avec les bases de données pour stocker, organiser, rechercher, modifier et sécuriser toutes les informations du site (utilisateurs, catalogues, commandes).

Boîte à outils du développeur

  • IDE comme VS Code : (Environnement de Développement Intégré) Un logiciel qui regroupe dans une seule interface l'ensemble des outils nécessaires pour écrire, tester et déboguer du code.
  • Github : Une plateforme web d'hébergement de code source et de collaboration basée sur Git.
  • Librairies / bibliothèques : Un ensemble de code pré-écrit, réutilisable qu'un développeur peut intégrer dans son programme pour exécuter des tâches courantes sans avoir à tout réinventer .
  • Frameworks : (Cadre de travail) Un ensemble structuré d’outils, de bibliothèques, de conventions et de composants qui fournit une base pour développer une application plus rapidement et de manière organisée.
    Il impose ou propose une structure de développement sur laquelle les développeurs peuvent s’appuyer, évitant ainsi de devoir recréer certaines fonctionnalités et organisations de base à partir de zéro.
    Exemples :
    - React    -> JavaScript
    - Spring   -> Java
    - Django -> Python
